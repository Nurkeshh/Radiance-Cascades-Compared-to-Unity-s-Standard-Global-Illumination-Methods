## About This Project

This repo is about comparing Radiance Cascades with the normal global illumination methods in Unity.
It is connected to the paper "Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP".
The idea is to see how each method affects FPS in real-time scenes.

## What is inside

- Measured Data - the results of the tests. It has 3 folders for different scenes: Isometric, Realistic FPS and Stylized FPS
- LICENSE - the license of the project
- README.md - this file

## What you can find

- Raw FPS and frame time data
